# Leo Li monogram

Two forward-leaning Ls use square elbows, broad stems and parallel 45-degree cut ends. The offset shapes form a compact, angular signature with a clear negative-space channel. The mark uses only straight edges and works in a single color without gradients or fine detail.

- `src/components/Logo.tsx`: inline header mark; inherits the active palette's foreground color, including light/dark and ASCII presentation.
- `public/logo.svg`: transparent vector master in dark ink.
- `public/logo.png`: transparent 512px PNG export.
- `public/favicon.svg`: the same mark in soft white on a graphite tile for browser tabs.
- `docs/brand/logo-preview.png`: light/dark study with 16, 24, 32 and 44px size checks, rendered directly from SVG.

The header keeps a 44px home-link target and its accessible name. The mark is decorative to screen readers and uses no hover transform. Geometry uses a 42×42 viewBox; retain its built-in clear space when exporting.
